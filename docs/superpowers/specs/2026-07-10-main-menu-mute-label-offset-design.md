# Смещение подписи кнопки звука во всех меню

## Цель

Поднять текстовую подпись общей кнопки звука во всех меню на 4 px, чтобы надпись «Заглушено» визуально располагалась по центру неоновой рамки.

## Решение

- Установить в общем компоненте `TopRightMuteButton` вертикальное смещение текста `-4` px по умолчанию.
- Удалить частную настройку `-4` px из `MainMenuScene`.
- Не изменять рамку, положение кнопки и область клика.
- Применить одинаковое смещение во всех сценах, использующих общий компонент.
- Смещение одинаково применяется к состояниям «Звук» и «Заглушено» и к обеим локалям.

## Проверка

- Тест компонента подтверждает смещение текста с `y = 20` до `y = 16` без дополнительных настроек сцены.
- Явная настройка `textOffsetY` при необходимости продолжает переопределять значение по умолчанию.
- Полный набор тестов и production-сборка должны завершиться успешно.
