# Определение языка из URL Yandex Games

## Цель

Открывать английский интерфейс сразу при запуске игры с параметром `?lang=en`, даже если язык браузера русский и Yandex SDK ещё не завершил инициализацию.

## Причина дефекта

Phaser запускается параллельно с `YaGames.init()`. Главное меню создаётся раньше, чем SDK записывает язык в `window.__yaSdkLang`, поэтому первоначальная локаль ошибочно берётся из `navigator.language`.

## Решение

`I18nService.detectLanguage()` проверяет параметр `lang` в URL игрового iframe до SDK и браузера. Поддерживаются `ru` и `en`; кириллические языки `be`, `uk`, `kk`, `uz` отображаются как RU, остальные известные значения — как EN.

Итоговый приоритет:

1. Ручной выбор RU/EN в памяти текущей страницы.
2. Параметр `lang` URL игрового iframe.
3. Язык Yandex SDK из `window.__yaSdkLang`.
4. `navigator.language`.
5. `DEFAULT_LANGUAGE`.

## Ограничения

- Запуск Phaser не ожидает SDK, поэтому защита от белого экрана сохраняется.
- `localStorage` не определяет язык.
- Невалидный или отсутствующий `lang` не мешает существующим резервным источникам.
- Ручное переключение продолжает работать до полной перезагрузки страницы.

## Проверка

- `?lang=en` возвращает EN при русском браузере.
- `?lang=ru` возвращает RU при английском браузере.
- Ручной выбор имеет приоритет над URL.
- При отсутствии `lang` сохраняется определение через SDK/браузер.
- Полный набор тестов и production-сборка проходят.
